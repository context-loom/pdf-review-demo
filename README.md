# PDF Review Demo

Static browser demo with PDF.js and the shared Graphic Editor Core.

Built from `context-loom/pdf-review` commit `dc164f4fe2b99e5b4706470b0502b9b2e89adc64`.

GitHub Pages: publish `main` → `/ (root)`.

The PDF is a synthetic test fixture. Annotation state is held in memory; stamp templates and placeholder defaults are saved locally in your browser.

PDF.js and bundled fonts retain their licenses under `vendor/`.
